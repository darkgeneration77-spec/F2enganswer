Original Text / 原文

Nowadays, water systems has been pollute by pesticides, fertilisers, and herbicides when it runs off the surface. By using organic methods to gotten rid of pests, pollution from these source can be reduced. These chemicals too should be used far from streams, wells, drains or lakes. Floating boom is also one of the solutions. It act as a barrier which can capture and throw away the floating pollutants. Pads, socks or absorbent booms can be used and absorb and removing oil spills. Oil can turn into sludge because it should not dissolve in water. This will cause the sludge to sticks to bird feathers, suffocate fish or block sunlight from reaching plants. Eventually, its will cause a disturbance to the food chain. By used the floating containment booms can stop oil from spreading. To remove the floating oil, oil skimmers can be used.

Answer Key + Explanation / 答案与解释

(a) gotten → get
“to” 后面用动词原形：to get rid of。
口诀：to + V1。
(b) source → sources
前面有 these，后面的可数名词要用复数。
these + plural noun。
(c) too → also
这里要把“也”放在助动词前的句中位置，also 更符合结构：These chemicals also should be used...
句中“也”常用 also。
(d) act → acts
主语 It 是第三人称单数，一般现在时动词加 -s。
He / She / It + V-s。
(e) and → to
can be used to + verb 表示“被用来做……”。这里是 used to absorb。
be used to + V1 = 被用来。
(f) removing → remove
前面是 absorb and ...，并列结构要一致：absorb and remove。
and 前后词性/形式要平行。
(g) should not → does not
这里陈述油“不溶于水”的事实，不是在表达“应该不”。应使用一般现在时否定。
事实：does not + V1。
(h) sticks → stick
结构是 cause + object + to + V1：cause the sludge to stick。
to 后面回到原形。
(i) its → it
这里需要主语代词：it will cause。its 是所有格，后面通常接名词。
it = 它；its = 它的。
(j) used → using
原文以 By 开头，因此后面应接 V-ing：By using...
By + V-ing = 通过……。

Fast Method / 做题口诀

1. 看 signal word： to → V1；these → plural；By → V-ing。
2. 看主语： He / She / It → 一般现在时 V-s。
3. 看平行： A and B 必须保持相同形式。
4. 看代词： it 是主语；its 是所有格。
5. 看句意： 事实通常用一般现在时，不要被 should 之类情态词带跑。
