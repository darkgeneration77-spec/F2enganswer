(a) them

Correct answer / 正确答案： them
Key Grammar / 关键语法： object pronoun / 宾格代词
Why? / 为什么？
Them is used after a verb or preposition as an object.
them 在动词或介词后作宾语。
Teacher Focus / 老师讲解： they 主格；them 宾格；their 所有格。

(b) highly

Correct answer / 正确答案： highly
Key Grammar / 关键语法： adverb / 副词
Why? / 为什么？
Highly modifies an adjective or verb and means 'to a high degree'.
highly 是副词，表示“高度地”。
Teacher Focus / 老师讲解： 形容词 high 与副词 highly 要分清。

(c) harsh

Correct answer / 正确答案： harsh
Key Grammar / 关键语法： adjective / 形容词
Why? / 为什么？
Harsh is the adjective required to describe a noun or condition.
这里需要形容词 harsh 来描述名词/情况。
Teacher Focus / 老师讲解： be + adjective 或 adjective + noun。

(d) protect

Correct answer / 正确答案： protect
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The structure requires the base verb protect.
句型需要动词原形 protect。
Teacher Focus / 老师讲解： 检查 modal/to/parallel verbs。

(e) resources

Correct answer / 正确答案： resources
Key Grammar / 关键语法： plural noun / 名词复数
Why? / 为什么？
The passage refers to resources generally in the plural.
这里泛指多种资源，因此使用 resources。
Teacher Focus / 老师讲解： 可数名词泛指多项时常用复数。

(f) down

Correct answer / 正确答案： down
Key Grammar / 关键语法： phrasal verb particle / 短语动词
Why? / 为什么？
Down completes the phrasal expression used in the passage.
down 用来完成文中的短语动词。
Teacher Focus / 老师讲解： Phrasal verb 要整组记。

(g) contributed

Correct answer / 正确答案： contributed
Key Grammar / 关键语法： past tense/participle / 过去式
Why? / 为什么？
Contributed matches the tense or participle structure of the sentence.
句子时态/结构需要 contributed。
Teacher Focus / 老师讲解： 先找时间线索，再决定 tense。

(h) fuel

Correct answer / 正确答案： fuel
Key Grammar / 关键语法： noun / 名词
Why? / 为什么？
Fuel is the correct noun form required by the context.
这里需要名词 fuel。
Teacher Focus / 老师讲解： 判断空格前后的冠词、形容词与动词。

(i) from

Correct answer / 正确答案： from
Key Grammar / 关键语法： preposition / 介词
Why? / 为什么？

Teacher Focus / 老师讲解： 介词题优先检查 collocation。

Correct answer / 正确答案： benefitted
Key Grammar / 关键语法： past tense/participle / 过去式

Teacher Focus / 老师讲解： 时态必须和整段时间背景一致。
