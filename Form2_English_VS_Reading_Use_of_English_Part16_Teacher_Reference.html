答案完全跟上传答案表。老师版重点解释每个正确词在句子里应检查的语法位置。

(a) stop

Correct answer / 正确答案： stop
Key Grammar / 关键语法： verb form / 动词形式
Why? / 为什么？
Use the base verb stop where the sentence structure requires the verb in its basic form.
句型需要动词原形时使用 stop。
Teacher Focus / 老师讲解： 先找前面的 modal / to / imperative，再决定动词形式。

(b) under

Correct answer / 正确答案： under
Key Grammar / 关键语法： preposition / 介词
Why? / 为什么？
Under is the required preposition in the phrase used in the passage.
这里需要介词 under 才能组成正确搭配。
Teacher Focus / 老师讲解： 介词题不要逐字翻译，要看固定搭配。

(c) leave

Correct answer / 正确答案： leave
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The sentence requires the base form leave.
句子结构要求使用动词原形 leave。
Teacher Focus / 老师讲解： 检查前面是否有 modal、to 或并列动词。

(d) container

Correct answer / 正确答案： container
Key Grammar / 关键语法： singular noun / 单数名词
Why? / 为什么？
The context requires the singular noun container.
根据句子数量关系，这里使用单数 container。
Teacher Focus / 老师讲解： 先找冠词 a/an/each/this 等数量提示。

(e) it

Correct answer / 正确答案： it
Key Grammar / 关键语法： pronoun / 代词
Why? / 为什么？
Use it to refer back to a singular thing already mentioned.
it 用来代替前面已经提过的单数事物。
Teacher Focus / 老师讲解： 分清 it（它）与 its（它的）。

(f) by

Correct answer / 正确答案： by
Key Grammar / 关键语法： preposition / method / 方法
Why? / 为什么？
By is used to show the method or means of doing something.
by 可表示“通过某种方法”。
Teacher Focus / 老师讲解： 常见结构：by + V-ing。

(g) wasted

Correct answer / 正确答案： wasted
Key Grammar / 关键语法： past participle/adjective / 过去分词
Why? / 为什么？
Wasted is required by the passive or descriptive structure in the sentence.
句子需要过去分词 wasted 来构成被动或描述状态。
Teacher Focus / 老师讲解： 看到 be 动词时检查是否需要 past participle。

(h) run

Correct answer / 正确答案： run
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The grammar pattern requires run, not an inflected form.
该句型要求动词原形 run。
Teacher Focus / 老师讲解： Modal + V1 / to + V1 是高频考点。

(i) collect

Correct answer / 正确答案： collect
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
Use collect in the base form according to the surrounding verb pattern.
根据前后句型，这里使用 collect 原形。
Teacher Focus / 老师讲解： 检查并列结构，两个动词形式通常要一致。

(j) your

Correct answer / 正确答案： your
Key Grammar / 关键语法： possessive adjective / 所有格
Why? / 为什么？
Your must come before a noun to show possession.
your 放在名词前表示“你的”。
Teacher Focus / 老师讲解： your + noun；yours 单独使用。
