答案完全跟上传答案表。老师版重点解释每个正确词在句子里应检查的语法位置。

(a) positivity

Correct answer / 正确答案： positivity
Key Grammar / 关键语法： noun / 名词
Why? / 为什么？
Positivity is the noun form required in the sentence.
这里需要名词 positivity，表示积极性/正面态度。
Teacher Focus / 老师讲解： positive = adjective；positivity = noun。

(b) you

Correct answer / 正确答案： you
Key Grammar / 关键语法： pronoun / 代词
Why? / 为什么？
You is the correct subject/object pronoun required by the sentence.
这里需要代词 you。
Teacher Focus / 老师讲解： 根据位置判断 subject/object。

(c) who

Correct answer / 正确答案： who
Key Grammar / 关键语法： relative pronoun / 关系代词
Why? / 为什么？
Use who to refer to a person in a relative clause.
who 用来指人，并引导关系从句。
Teacher Focus / 老师讲解： person → who；thing → which/that。

(d) Having

Correct answer / 正确答案： Having
Key Grammar / 关键语法： gerund/participle / V-ing
Why? / 为什么？
Having begins the required -ing structure.
这里需要 Having 开始 V-ing 结构。
Teacher Focus / 老师讲解： 句首 V-ing 可作主语或分词结构。

(e) easiest

Correct answer / 正确答案： easiest
Key Grammar / 关键语法： superlative / 最高级
Why? / 为什么？
Easiest is the superlative form used when comparing three or more possibilities.
easiest 是 easy 的最高级，表示“最容易的”。
Teacher Focus / 老师讲解： easy → easier → easiest。

(f) when

Correct answer / 正确答案： when
Key Grammar / 关键语法： conjunction / 连词
Why? / 为什么？
When introduces the time relationship required by the sentence.
when 引导时间关系，表示“当……时”。
Teacher Focus / 老师讲解： 先判断句子需要时间、原因还是条件连接词。

(g) is

Correct answer / 正确答案： is
Key Grammar / 关键语法： subject–verb agreement / 主谓一致
Why? / 为什么？
The singular subject takes is.
单数主语搭配 is。
Teacher Focus / 老师讲解： 先圈主语，再决定 is/are。

(h) use

Correct answer / 正确答案： use
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The structure requires the base form use.
这里使用动词原形 use。
Teacher Focus / 老师讲解： modal/to 后用 V1。

(i) feel

Correct answer / 正确答案： feel
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The grammar pattern requires feel in its base form.
句型要求使用 feel 原形。
Teacher Focus / 老师讲解： 检查主语与助动词。

(j) are

Correct answer / 正确答案： are
Key Grammar / 关键语法： subject–verb agreement / 主谓一致
Why? / 为什么？
A plural subject takes are.
复数主语搭配 are。
Teacher Focus / 老师讲解： 先找真正主语，别被中间名词骗。
