Answer Summary
Topic / 主题： Smart shopping and budgeting
Answer Key: a your · b stick · c so · d or · e wait · f shop · g carry · h buy · i are · j items

本版本把答案直接放回错误词旁边，并解释 为什么要这样改、关键语法是什么。答案严格按照上传答案表。

(a) yours → your

Original error / 原错误： yours
Correct answer / 正确答案： your
Key clue / 关键： before noun 'list'
Why? / 为什么？
A possessive adjective is needed before a noun: your list.
名词 list 前要用形容词性物主代词 your。
Teacher Focus / 教学重点： your + noun; yours stands alone.

(b) sticking → stick

Original error / 原错误： sticking
Correct answer / 正确答案： stick
Key clue / 关键： Don't over-withdraw ... and stick
Why? / 为什么？
After Don't, coordinated verbs use the base form.
Don't 后并列动词使用原形，因此是 stick。
Teacher Focus / 教学重点： Imperative parallelism.

(c) therefore → so

Original error / 原错误： therefore
Correct answer / 正确答案： so
Key clue / 关键： cause/result connector
Why? / 为什么？
The answer key uses so to link the result naturally in this sentence.
这里表达结果关系，答案表使用 so。
Teacher Focus / 教学重点： Connector choice.

(d) and → or

Original error / 原错误： and
Correct answer / 正确答案： or
Key clue / 关键： wallet or purse
Why? / 为什么？
The sentence presents alternative places where extra money may be kept, so or is used.
wallet 与 purse 在这里是选择关系，所以用 or。
Teacher Focus / 教学重点： and vs or.

(e) waiting → wait

Original error / 原错误： waiting
Correct answer / 正确答案： wait
Key clue / 关键： such as + verb form in key context
Why? / 为什么？
The supplied answer key changes waiting to wait.
答案表指定 waiting 改为 wait。
Teacher Focus / 教学重点： Follow supplied key.

(f) shops → shop

Original error / 原错误： shops
Correct answer / 正确答案： shop
Key clue / 关键： each + singular noun
Why? / 为什么？
After each, use a singular noun: each shop.
each 后面接单数名词，所以用 shop。
Teacher Focus / 教学重点： each + singular.

(g) carried → carry

Original error / 原错误： carried
Correct answer / 正确答案： carry
Key clue / 关键： can try to + base verb
Why? / 为什么？
After to, use the base verb carry.
to 后面接动词原形 carry。
Teacher Focus / 教学重点： to + V1.

(h) bought → buy

Original error / 原错误： bought
Correct answer / 正确答案： buy
Key clue / 关键： will only + base verb
Why? / 为什么？
After modal will, use the base verb buy.
will 后面接动词原形 buy。
Teacher Focus / 教学重点： Modal + V1.

(i) were → are

Original error / 原错误： were
Correct answer / 正确答案： are
Key clue / 关键： general present advice
Why? / 为什么？
The passage gives general present advice, so are fits.
整段是一般性的购物建议，因此用现在时 are。
Teacher Focus / 教学重点： Tense consistency.

(j) item → items

Original error / 原错误： item
Correct answer / 正确答案： items
Key clue / 关键： more + plural count noun
Why? / 为什么？
After more, use the plural count noun items.
more 后面这里接可数名词复数 items。
Teacher Focus / 教学重点： Plural noun.
