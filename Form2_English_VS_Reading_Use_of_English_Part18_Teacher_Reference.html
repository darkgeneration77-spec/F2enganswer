(a) live

Correct answer / 正确答案： live
Key Grammar / 关键语法： verb/adjective form / 词形
Why? / 为什么？
The answer key requires live; its form fits the grammatical position in the sentence.
答案表指定 live，其词形符合句子位置。
Teacher Focus / 老师讲解： 判断需要 live / lives / living 时先找主语与助动词。

(b) complaints

Correct answer / 正确答案： complaints
Key Grammar / 关键语法： plural noun / 名词复数
Why? / 为什么？
The context requires the plural noun complaints.
上下文需要复数 complaints。
Teacher Focus / 老师讲解： 可数名词出现 many/several 等提示时要用复数。

(c) takes

Correct answer / 正确答案： takes
Key Grammar / 关键语法： subject–verb agreement / 主谓一致
Why? / 为什么？
A singular third-person subject takes takes.
第三人称单数主语搭配 takes。
Teacher Focus / 老师讲解： He/She/It + V-s。

(d) is

Correct answer / 正确答案： is
Key Grammar / 关键语法： subject–verb agreement / 主谓一致
Why? / 为什么？
The singular subject takes is.
单数主语搭配 is。
Teacher Focus / 老师讲解： 先圈主语，再决定 is/are。

(e) lose

Correct answer / 正确答案： lose
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
The surrounding structure requires the base verb lose.
前后结构要求动词原形 lose。
Teacher Focus / 老师讲解： Modal + V1。

(f) better

Correct answer / 正确答案： better
Key Grammar / 关键语法： comparative adjective / 比较级
Why? / 为什么？
Better is the comparative form of good/well.
better 是 good/well 的比较级。
Teacher Focus / 老师讲解： 出现 than 或两者比较时考虑 comparative。

(g) working

Correct answer / 正确答案： working
Key Grammar / 关键语法： V-ing / 动名词或现在分词
Why? / 为什么？
The sentence requires the -ing form working.
句型要求使用 working 的 -ing 形式。
Teacher Focus / 老师讲解： 介词后常用 V-ing；也检查进行时。

(h) send

Correct answer / 正确答案： send
Key Grammar / 关键语法： base verb / 动词原形
Why? / 为什么？
Use send after a structure that requires the base verb.
这里的句型要求动词原形 send。
Teacher Focus / 老师讲解： to/modal 后检查 V1。

(i) very

Correct answer / 正确答案： very
Key Grammar / 关键语法： adverb of degree / 程度副词
Why? / 为什么？
Very intensifies an adjective or adverb.
very 用来加强形容词或副词的程度。
Teacher Focus / 老师讲解： very + adjective/adverb。

(j) transport

Correct answer / 正确答案： transport
Key Grammar / 关键语法： uncountable/general noun / 名词
Why? / 为什么？
Transport is the appropriate general noun in this context.
这里使用 transport 表示交通/运输的整体概念。
Teacher Focus / 老师讲解： 不要随意加复数 -s。
