Answer Summary
Topic / 主题： Water pollution and oil spills
Answer Key: a get · b this · c also · d acts · e to · f remove · g cannot · h stick · i it · j using

本版本把答案直接放回错误词旁边，并解释 为什么要这样改、关键语法是什么。答案严格按照上传答案表。

(a) gotten → get

Original error / 原错误： gotten
Correct answer / 正确答案： get
Key clue / 关键： to get rid of
Why? / 为什么？
The fixed phrase is get rid of. After “to”, use the base form get.
固定搭配是 get rid of；to 后用动词原形 get。
Teacher Focus / 教学重点： Phrasal verb.

(b) these → this

Original error / 原错误： these
Correct answer / 正确答案： this
Key clue / 关键： source = singular
Why? / 为什么？
The noun source is singular, so use this.
source 是单数，因此用 this。
Teacher Focus / 教学重点： Demonstrative agreement.

(c) too → also

Original error / 原错误： too
Correct answer / 正确答案： also
Key clue / 关键： sentence connector
Why? / 为什么？
Here the meaning is “in addition”, so the answer key uses also.
这里表达“也、另外”，答案表用 also。
Teacher Focus / 教学重点： too vs also position.

(d) act → acts

Original error / 原错误： act
Correct answer / 正确答案： acts
Key clue / 关键： Floating boom = singular
Why? / 为什么？
The subject is singular, so the verb takes -s: acts.
主语 Floating boom 是单数，因此动词用 acts。
Teacher Focus / 教学重点： Subject–verb agreement.

(e) and → to

Original error / 原错误： and
Correct answer / 正确答案： to
Key clue / 关键： be used to absorb
Why? / 为什么？
The structure is be used to + verb, so to is required.
固定结构 be used to + 动词，因此用 to。
Teacher Focus / 教学重点： Verb pattern.

(f) removing → remove

Original error / 原错误： removing
Correct answer / 正确答案： remove
Key clue / 关键： absorb and remove
Why? / 为什么？
The coordinated verbs should be in the same form: absorb and remove.
并列动词形式要一致：absorb and remove。
Teacher Focus / 教学重点： Parallel structure.

(g) should → cannot

Original error / 原错误： should
Correct answer / 正确答案： cannot
Key clue / 关键： oil does not dissolve in water
Why? / 为什么？
The intended meaning is that oil cannot dissolve in water.
这里表达油不能溶于水，所以用 cannot。
Teacher Focus / 教学重点： Modal meaning.

(h) sticks → stick

Original error / 原错误： sticks
Correct answer / 正确答案： stick
Key clue / 关键： to + base verb
Why? / 为什么？
After to, use the base form: to stick.
to 后面接动词原形 stick。
Teacher Focus / 教学重点： to + V1.

(i) its → it

Original error / 原错误： its
Correct answer / 正确答案： it
Key clue / 关键： pronoun subject
Why? / 为什么？
The pronoun refers to the sludge as the subject, so use it, not possessive its.
这里代词作主语，指 sludge，所以用 it，不是所有格 its。
Teacher Focus / 教学重点： it vs its.

(j) used → using

Original error / 原错误： used
Correct answer / 正确答案： using
Key clue / 关键： By + -ing
Why? / 为什么？
After by to show method, use the -ing form: by using.
by 表示方法时，后面接 V-ing，所以用 using。
Teacher Focus / 教学重点： by + V-ing.
