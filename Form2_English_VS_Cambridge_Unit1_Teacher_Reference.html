A. Write questions using “be going to”

1. you/work today?
Answer / 答案： Are you going to work today?
Key clue / 关键： you → are; work stays in base form
Why? / 为什么？
For a question with you, use Are + you + going to + base verb.
主语是 you，疑问句结构是 Are + you + going to + 动词原形。
Teacher focus / 教学重点： be going to = planned future（计划中的未来）
2. you/recycle the things over here?
Answer / 答案： Are you going to recycle the things over here?
Key clue / 关键： you → are; recycle = base verb
Why? / 为什么？
The sentence asks about a future intention, so the structure is Are you going to recycle...?
题目问未来打算，因此用 Are you going to + recycle。
Teacher focus / 教学重点： Do not change the main verb after “going to”.
3. you/be a CEO twenty years from now?
Answer / 答案： Are you going to be a CEO twenty years from now?
Key clue / 关键： twenty years from now → future; be remains base form
Why? / 为什么？
After going to, the verb must be in the base form, so we use be.
going to 后面一定接动词原形，所以这里保留 be。
Teacher focus / 教学重点： Time clue: twenty years from now（20年后）
4. your/parents let you work part time?
Answer / 答案： Are your parents going to let you work part time?
Key clue / 关键： parents = plural → are
Why? / 为什么？
Parents is plural, so the correct be-verb is are.
parents 是复数，所以 be 动词使用 are。
Teacher focus / 教学重点： Plural subject → are
5. you/sell the old books?
Answer / 答案： Are you going to sell the old books?
Key clue / 关键： you → are; sell = base verb
Why? / 为什么？
Use the question pattern Are you going to + sell...?
使用疑问结构 Are you going to + sell。
Teacher focus / 教学重点： Question word order
6. Mary/set up her own business?
Answer / 答案： Is Mary going to set up her own business?
Key clue / 关键： Mary = singular → is
Why? / 为什么？
Mary is one person, so use Is before the subject.
Mary 是单数第三人称，所以使用 Is。
Teacher focus / 教学重点： Singular subject → is
7. He/work in the supermarket for extra earnings?
Answer / 答案： Is he going to work in the supermarket for extra earnings?
Key clue / 关键： he = singular → is
Why? / 为什么？
With he, use Is he going to + base verb.
主语 he 搭配 is，后面接 going to + 动词原形。
Teacher focus / 教学重点： he/she/name → is

B. Reading: Tips for making money (KBAT)

Core passage clues for teachers: teenagers can put up an advert on a community noticeboard; take dogs for a walk; pet sit; do gardening; work in a hotel during school holidays; sell unused clothes, toys and books online; wash cars; deliver newspapers; do ironing. The passage also says these activities help teenagers save money, keep pocket money, gain experience and spend less.
1. What are the jobs you can do to make money?
Answer / 答案： The jobs we can do to make money are washing cars, delivering newspapers, ironing, gardening, working in a hotel and selling old things.
Key clue / 关键： washing cars / delivering newspapers / ironing / gardening / hotel / selling old things
Why? / 为什么？
The question asks for jobs. These activities are directly listed in the passage as ways teenagers can earn money.
题目关键词是 jobs（工作）。文章直接列出这些赚钱方式，所以把相关工作列出来即可。
Teacher focus / 教学重点： Scan for a list after “make money”.
2. How can you let people know about the jobs you are willing to do?
Answer / 答案： We can let people know what job we can do by putting up an advert on a community noticeboard.
Key clue / 关键： put up an advert + community noticeboard
Why? / 为什么？
The passage explains the method of informing others: place an advertisement on the community noticeboard.
题目问“如何让别人知道”，文章给出的方式是把广告贴在社区布告栏。
Teacher focus / 教学重点： How = method（方法）
3. What are the advantages of earning extra money?
Answer / 答案： The advantages of earning extra money are that we can save money to go on holidays, can keep pocket money and save some money for emergency purposes.
Key clue / 关键： save money / pocket money / emergency purposes
Why? / 为什么？
The answer key groups the benefits of extra income into saving for holidays, keeping pocket money and saving for emergencies.
答案表把额外收入的好处归纳为：假期储蓄、保留零用钱，以及为紧急用途存钱。
Teacher focus / 教学重点： Advantages = benefits（好处）
4. In your opinion, list five most enjoyable jobs that you would love to do. (KBAT)
Answer / 答案： I would love to sell cakes and cookies, bring old people for walking, babysit, do washing-up and deliver food.
Key clue / 关键： In your opinion → acceptable personal choices; answer key provides one model
Why? / 为什么？
This is a KBAT/open-response item. The answer key gives a model list of five enjoyable jobs rather than one uniquely correct response.
这是开放式 KBAT 题。答案表提供五个示范工作，并不代表只有这一组答案才正确。
Teacher focus / 教学重点： For open answers, check relevance + five items.
5. List down 4 tips for saving money. (KBAT)
Answer / 答案： Spend less and not spend unnecessarily buying things, walk or cycle instead of using public transport, eat at home instead of eating outside, recycle things you have instead of buying a new one.
Key clue / 关键： spend less / walk or cycle / eat at home / recycle
Why? / 为什么？
Each point reduces unnecessary spending. The answer must contain four practical saving actions.
四个重点都围绕“减少不必要开销”：少花钱、步行或骑车、在家吃、重复利用物品。
Teacher focus / 教学重点： Count the required number: 4 tips.

C. would like / wouldn’t like

1. I would like / wouldn't like to work in the hotel during the summer as they need someone to tidy the rooms.
Answer / 答案： would like
Key clue / 关键： work opportunity / tidy the rooms
Why? / 为什么？
The sentence presents a suitable job opportunity, so the answer key chooses a positive preference: would like.
句子描述一个可做的工作机会，因此答案表选择正面意愿 would like（想要）。
Teacher focus / 教学重点： would like = want to politely（礼貌表达想要）
2. I would like / wouldn't like to shop in that mall. The price is so expensive.
Answer / 答案： wouldn't like
Key clue / 关键： so expensive
Why? / 为什么？
The negative clue so expensive explains why the speaker does not want to shop there.
so expensive（太贵） 是负面线索，因此选择 wouldn't like。
Teacher focus / 教学重点： Use meaning clues after the sentence.
3. Sherlyn would like / wouldn't like to have more pocket money, so she is putting up an advert on the community noticeboard.
Answer / 答案： would like
Key clue / 关键： have more pocket money / so
Why? / 为什么？
Putting up an advert shows Sherlyn wants to earn more money, so would like fits.
她贴广告是为了赚更多零用钱，说明她“想要”更多钱，所以用 would like。
Teacher focus / 教学重点： Cause-effect clue: so（所以）
4. Tina did not buy the gown because she knew Sally would / wouldn't like it.
Answer / 答案： wouldn't
Key clue / 关键： did not buy / because
Why? / 为什么？
Tina did not buy the gown because she believed Sally would not like it.
Tina 没买裙子，原因是她认为 Sally 不会喜欢，所以选择 wouldn't。
Teacher focus / 教学重点： Match cause with action.
5. Susan would like / wouldn't like to recycle old books.
Answer / 答案： would like
Key clue / 关键： recycle = positive action
Why? / 为什么？
The answer key chooses the positive form would like.
答案表选择正面形式 would like，表示 Susan 愿意回收旧书。
Teacher focus / 教学重点： Positive vs negative preference

D. Essay — “What will you do to earn extra money during holidays?”

Model answer / 参考答案： The following essay is reproduced from the uploaded answer key for teacher reference.
Working during the holidays to make some money is a good way. Not only a way to get some income but we can spend our holiday in a worthwhile way. We can get new experiences and meet new people. I have a list to share on what I love to do during the holidays. I love to explore new jobs around. Usually my holidays are for two months. First and foremost, I will put an advert on the community noticeboard. I love to do ironing. Why do I say this? Our attire is the first thing people notice and it gives a whole idea to someone about our appearance. Wearing clean and tidy clothes will make us look clean and nice. I am very concerned about wearing a well ironed cloth. Therefore, I would find ironing interesting and that would make some money too. My charges would be reasonable and not too low as well. So, I can earn a good amount of money. Next, I would love to do gardening. Gardening includes watering flowers, cutting grass, cleaning the garden area and planting. Many people nowadays are too busy with work and have got no enough time to do these things. It is a great chance for me to make quite a number of earnings as many would need this service. Keeping the garden clean and planting more trees or flowers will make the surrounding environment clean and give fresh air. In addition, I would also love to deliver newspapers. This is a great idea! Many of us have the habit of reading a newspaper every day. Therefore, it will be a great job as I can deliver many newspapers. Definitely, I will be earning a good amount of money. Moreover, delivering newspapers to peoples' houses is convenient for them and many will look for a delivery. I am not only earning some money but also reminding them to read daily updates. I will need to get up early in the morning to deliver the newspapers but it will be a great experience though. Lastly, I would love to pet sit and bring them for a walk. It will be so enjoyable that I can play with the pet while I take them for a walk. I can also get some fresh air going for a walk with them. It is a work where I can relieve stress while working. I love puppies and there are many in my neighbourhood. Perhaps, it is the right job to do here. In a nutshell, it is good to work on holidays. It gives us experience and helps us in many ways like earning some pocket money or to save money and also to learn new things. I would encourage my friends and teenagers out there to try this.
How to teach it / 如何讲解：
The answer is organised by job ideas: ironing → gardening → delivering newspapers → pet sitting. Each body paragraph explains what the job involves and why it is useful or enjoyable.
范文以四种工作为主体：熨衣 → 园艺 → 送报纸 → 照顾宠物。每一段不仅写“做什么”，还解释“为什么适合 / 有什么好处”。老师可让学生抓住“工作 + 做法 + 好处”这个结构。
Key writing frame / 写作关键： Job idea → What I will do → Why → Benefit / earning.

E. Choose the correct word — Pronouns

1. Taranya is happy because ______ is going on a holiday soon. (her / they / she)
Answer / 答案： she
Key clue / 关键： blank is the subject before “is going”
Why? / 为什么？
We need a subject pronoun. Taranya is one female person, so she is correct.
空格位于动词 is going 前，需要主格代词。Taranya 是女性单数，所以用 she。
Teacher focus / 教学重点： Subject pronoun: she
2. It has started to snow so ______ need to buy thick clothes. (they / we / us)
Answer / 答案： we
Key clue / 关键： blank is the subject before “need”
Why? / 为什么？
The answer key uses we, a subject pronoun. Us cannot be used as the subject.
答案表使用 we，因为空格是主语位置；us 是宾格，不能放在这里作主语。
Teacher focus / 教学重点： Subject vs object pronoun
3. Mei Kee loves to take photographs. ______ photographs look very good. (She / Her / His)
Answer / 答案： Her
Key clue / 关键： before noun “photographs” → possessive adjective
Why? / 为什么？
A possessive adjective is needed before the noun photographs. For Mei Kee, the answer key gives Her.
名词 photographs 前要用形容词性物主代词，因此答案是 Her。
Teacher focus / 教学重点： her + noun
4. We are going for the show. Aunt Sheila is taking ______. (we / us / them)
Answer / 答案： us
Key clue / 关键： after verb “taking” → object
Why? / 为什么？
The pronoun comes after the verb taking, so an object pronoun is needed: us.
代词放在动词 taking 后面作宾语，因此用宾格 us。
Teacher focus / 教学重点： we → us after a verb
5. Mum and I are going to the supermarket. ______ want to buy some groceries. (She / We / Us)
Answer / 答案： We
Key clue / 关键： Mum and I = we
Why? / 为什么？
Mum and I refers to two people including the speaker, so the subject pronoun is We.
Mum and I 包括“我”和妈妈，两个人合起来用 We。
Teacher focus / 教学重点： Combine nouns into pronouns
6. Jacinth helped to pet sit Uncle Lim's dog until ______ returns. (they / he / I)
Answer / 答案： he
Key clue / 关键： Uncle Lim = one male person
Why? / 为什么？
The pronoun refers to Uncle Lim, one male person, so he is correct.
代词指代 Uncle Lim，一位男性单数，所以用 he。
Teacher focus / 教学重点： Pronoun reference（指代）

H. Complete with simple past tense

1. I (help) them do ironing during the holidays.
Answer / 答案： helped
Key clue / 关键： regular verb help + -ed
Why? / 为什么？
The past form of the regular verb help is helped.
规则动词 help 的过去式加 -ed → helped。
Teacher focus / 教学重点： Regular past: verb + ed
2. Irene (spend) nearly RM100 yesterday.
Answer / 答案： spent
Key clue / 关键： yesterday + irregular verb spend → spent
Why? / 为什么？
Yesterday signals past time. Spend is irregular, so its past form is spent.
yesterday 是过去时间线索；spend 是不规则动词，过去式是 spent。
Teacher focus / 教学重点： Time clue + irregular verb
3. Mom and I (shop) in IOI City Mall last week.

Why? / 为什么？
Last week requires past tense. For shop, double the final consonant and add -ed: shopped.
last week 表示过去；shop 变过去式时双写 p 再加 ed → shopped。
Teacher focus / 教学重点： CVC spelling rule
4. Ima (work) in a restaurant to save some money for her studies.

Key clue / 关键： work → worked
Why? / 为什么？
The answer key uses the simple past form worked.

固定搭配是 take part in（参加）；will 后面用动词原形 take。
Teacher focus / 教学重点： Collocation: take part in
3. next / the / charity / perform / concert / week / they / at
Answer / 答案： They will perform at the charity concert next week.
Key clue / 关键： they + will perform + at + event + time
Why? / 为什么？
The sentence follows subject → future verb → place/event → time.
句子顺序：主语 → will + 动词 → 地点/活动 → 时间。
Teacher focus / 教学重点： Word order
4. money / This / charity / given / suitable / will / that / collected / to / we / be / a
Answer / 答案： This money that we collected will be given to a suitable charity.
Key clue / 关键： will be given = future passive
Why? / 为什么？
The money receives the action, so the answer uses the future passive will be given.
钱是“被捐出去”的对象，所以使用未来被动语态 will be given。
Teacher focus / 教学重点： Future passive: will be + past participle
5. blowing / as / there / think / wind / be / storm / the / is / very strongly / I / a
Answer / 答案： I think there will be a storm as the wind is blowing very strongly.
Key clue / 关键： there will be + evidence
Why? / 为什么？
The sentence gives a prediction and then evidence: the wind is blowing very strongly.
句子先作预测“会有暴风雨”，再用“大风正在强烈地吹”作为依据。
Teacher focus / 教学重点： Prediction with will
6. odd jobs / she / do / Tina / whenever / is / free
Answer / 答案： Tina will do odd jobs whenever she is free.
Key clue / 关键： Tina + will do + whenever clause
Why? / 为什么？
Use will do in the main clause. After whenever, the answer uses present tense is.
主句使用 will do；whenever 引导的时间从句使用现在时 is。
Teacher focus / 教学重点： Future main clause + present time clause
