C. Present Perfect: has / have + past participle

1. Since I joined the Renaissance Club, I ______ (be) on many camping trips.
Answer / 答案：have been
Key clue / 关键：I → have; be → been
Why? / 为什么？
Use have with I and the past participle been.
I 搭配 have；be 的过去分词是 been。
Teacher focus / 教学重点：I/you/we/they → have
2. Mother ______ (book) our hotel rooms.
Answer / 答案：has booked
Key clue / 关键：Mother = singular → has
Why? / 为什么？
A singular third-person subject takes has; book → booked.
Mother 是第三人称单数，用 has；book → booked。
Teacher focus / 教学重点：he/she/name → has
3. Meera ______ (write) an email to her friend in France.
Answer / 答案：has written
Key clue / 关键：Meera → has; write → written
Why? / 为什么？
Write is irregular: write–wrote–written.
write 是不规则动词：write–wrote–written。
Teacher focus / 教学重点：Memorise irregular participles
4. Tommy wants to go hiking because he ______ never ______ (do) it before.
Answer / 答案：has, done
Key clue / 关键：he → has; do → done
Why? / 为什么？
Never fits between has and the past participle: has never done.
never 放在 has 与过去分词之间：has never done。
Teacher focus / 教学重点：has/have + never + PP
5. I ______ (finish) the house chores so I can go out for movie.
Answer / 答案：have finished
Key clue / 关键：I → have; finish → finished
Why? / 为什么？
The present perfect form is have finished.
I 用 have，finish 的过去分词是 finished。
Teacher focus / 教学重点：Present perfect result
6. He ______ (sail) by ship to sight see on a windy day.
Answer / 答案：has sailed
Key clue / 关键：He → has; sail → sailed
Why? / 为什么？
He takes has; sailed is the past participle.
He 搭配 has；sail → sailed。
Teacher focus / 教学重点：Subject–auxiliary agreement
