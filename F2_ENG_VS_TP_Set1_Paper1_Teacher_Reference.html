Q1. The poster reminds visitors not to
A. enjoy their trip at the park
B. destroy the plants
C. drop litter in the park
Answer / 答案： C — drop litter in the park
Key clue / 关键： “leave nothing but footprints”
Why? / 为什么？
The environmental slogan means visitors should leave no rubbish behind. The purpose is to keep the park clean.
环保标语“只留下脚印”表示不要留下垃圾，因此答案是不要在公园乱丢垃圾。
Why not the others? / 其他选项为什么错？
A. The poster actually encourages visitors to enjoy the trip.
B. Plant destruction is not the direct message of the slogan.
Teacher Focus / 教学重点： Interpret slogans by meaning, not literally. 标语题先找真正要读者采取的行动。
Q2. David wrote the message to
A. tell Mother that Uncle Kefli had to go to the supermarket
B. remind Mother to call Uncle Kefli immediately
C. inform Mother about Uncle Kefli's plan for tomorrow
Answer / 答案： B — remind Mother to call Uncle Kefli immediately
Key clue / 关键： “Please give him a ring as soon as you arrive home.”
Why? / 为什么？
The main purpose is the action David wants Mother to take: call Uncle Kefli as soon as she gets home.
信息的主要目的，是提醒妈妈一回家就打电话给 Uncle Kefli。其他内容只是背景。
Why not the others? / 其他选项为什么错？
A. Uncle Kefli wants a lift; the message does not say he 'had to go'.
C. That is only background information, not the main purpose.
Teacher Focus / 教学重点： Main-purpose question: focus on the requested action.

Part 2 — Error Correction (Q9–16)

Original passage focus / 原文： childhood memories with Tammy, village adventures, stolen mangoes and a boat ride.
Q9. friendliest → ______
Correct answer / 正确答案： friendly
Key Grammar / 关键语法： be + adjective; no comparison
Why? / 为什么？
After “was very”, we need the base adjective friendly. “Friendliest” is a superlative and requires a comparison group.
was very 后面使用普通形容词 friendly。friendliest 是最高级，需要明确比较范围。
Q10. a village → ______ village
Correct answer / 正确答案： the
Key Grammar / 关键语法： specific village already known
Why? / 为什么？
The passage refers to the specific village where the narrator stayed, so the definite article the is used.
这里指前面已经提到的那一个村庄，所以用定冠词 the。
Q11. we have together → we ______ together
Correct answer / 正确答案： had
Key Grammar / 关键语法： past narrative
Why? / 为什么？
The whole memory is told in the past, so had matches the time frame.
整段是在回忆过去，因此这里使用过去式 had。
Q12. naughty but we got into some mischief → naughty ______ we got into some mischief
Correct answer / 正确答案： and
Key Grammar / 关键语法： addition/sequence
Why? / 为什么？
The two ideas are additive, not contrasting: Tammy was naughty and they got into mischief.
这里不是转折，而是顺接：Tammy 很顽皮，而且她们闯了祸，所以用 and。
Q13. some mango → some ______
Correct answer / 正确答案： mangoes
Key Grammar / 关键语法： some + plural count noun
Why? / 为什么？
With the countable noun “mango”, some requires the plural form mangoes.
mango 是可数名词，some 后面使用复数 mangoes。
Q14. the sweet I’ve ever eaten → the ______ I’ve ever eaten
Correct answer / 正确答案： sweetest
Key Grammar / 关键语法： the + superlative + ever
Why? / 为什么？
The pattern “the ... I’ve ever eaten” requires a superlative: the sweetest.
“the ... I’ve ever eaten” 是最高级句型，因此用 sweetest。
Q15. go at a boat ride → go ______ a boat ride
Correct answer / 正确答案： on
Key Grammar / 关键语法： collocation: go on a ride
Why? / 为什么？
The fixed expression is go on a boat ride.
固定搭配是 go on a boat ride，所以介词用 on。
Q16. begged Tammy to rowed us back → to ______ us back
Correct answer / 正确答案： row
Key Grammar / 关键语法： to + base verb
Why? / 为什么？
After to, use the base verb: to row.
to 后面接动词原形，所以 rowed 改成 row。
