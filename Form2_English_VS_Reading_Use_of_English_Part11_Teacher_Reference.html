Answer Summary
Topic / 主题： Biodiesel and used cooking oil
Answer Key: a it · b and · c power · d support · e contamination · f promote · g repair · h into

本版本把答案直接放回错误词旁边，并解释 为什么要这样改、关键语法是什么。答案严格按照上传答案表。

(a) its → it

Original error / 原错误： its
Correct answer / 正确答案： it
Key clue / 关键： use + object pronoun
Why? / 为什么？
After use, we need an object pronoun. “It” refers to the used cooking oil.
use 后面需要宾格代词；it 指前面的 used cooking oil。
Teacher Focus / 教学重点： Pronoun: its = possessive; it = object pronoun.

(b) or → and

Original error / 原错误： or
Correct answer / 正确答案： and
Key clue / 关键： schools + fishing boats are both included
Why? / 为什么？
The sentence adds two groups, so and is needed, not a choice between them.
句子把 schools 和 fishing boats 两组都包括进来，所以用 and。
Teacher Focus / 教学重点： and = addition; or = choice.

(c) powered → power

Original error / 原错误： powered
Correct answer / 正确答案： power
Key clue / 关键： to + base verb
Why? / 为什么？
After to, use the base verb: to power.
to 后面接动词原形，所以是 power。
Teacher Focus / 教学重点： to + V1.

(d) supporting → support

Original error / 原错误： supporting
Correct answer / 正确答案： support
Key clue / 关键： protect ... and support
Why? / 为什么？
The verbs joined by and must be parallel: protect and support.
and 连接的动词形式要一致：protect and support。
Teacher Focus / 教学重点： Parallel structure.

(e) contaminate → contamination

Original error / 原错误： contaminate
Correct answer / 正确答案： contamination
Key clue / 关键： reduce + noun
Why? / 为什么？
After reduce, the sentence needs the noun contamination.
reduce 后面这里需要名词 contamination。
Teacher Focus / 教学重点： Word class: verb → noun.

(f) promoting → promote

Original error / 原错误： promoting
Correct answer / 正确答案： promote
Key clue / 关键： aims to + base verb
Why? / 为什么？
The pattern is aim to + verb: aims to promote.
固定结构 aims to + 动词原形，所以是 promote。
Teacher Focus / 教学重点： aim to + V1.

(g) repairing → repair

Original error / 原错误： repairing
Correct answer / 正确答案： repair
Key clue / 关键： clean and repair
Why? / 为什么？
After to, the two coordinated verbs must be base forms: clean and repair.
to 后面两个并列动词都用原形：clean and repair。
Teacher Focus / 教学重点： Parallel verbs.

(h) at → into

Original error / 原错误： at
Correct answer / 正确答案： into
Key clue / 关键： dump ... into drains
Why? / 为什么？
The natural preposition is dump into, meaning throw something into a place.
固定搭配 dump into，表示把东西倒进某处。
Teacher Focus / 教学重点： Preposition/collocation.
