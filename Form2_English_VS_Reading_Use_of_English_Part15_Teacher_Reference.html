Answer Summary
Topic / 主题： How a coach helps an athlete
Answer Key: a focused · b at · c a · d easily · e think · f set · g improvements · h drink · i your · j proper

本版本把答案直接放回错误词旁边，并解释 为什么要这样改、关键语法是什么。答案严格按照上传答案表。

(a) focus → focused

Original error / 原错误： focus
Correct answer / 正确答案： focused
Key clue / 关键： remain + adjective
Why? / 为什么？
After remain, use an adjective: remain focused.
remain 后面接形容词 focused。
Teacher Focus / 教学重点： Linking verb + adjective.

(b) in → at

Original error / 原错误： in
Correct answer / 正确答案： at
Key clue / 关键： work at improving
Why? / 为什么？
The answer key uses the collocation work at improving.
答案表使用固定搭配 work at improving。
Teacher Focus / 教学重点： Preposition/collocation.

(c) the → a

Original error / 原错误： the
Correct answer / 正确答案： a
Key clue / 关键： in a sport
Why? / 为什么？
The noun is introduced generally, so use the indefinite article a.
这里泛指一项运动，因此用 a sport。
Teacher Focus / 教学重点： Article use.

(d) easy → easily

Original error / 原错误： easy
Correct answer / 正确答案： easily
Key clue / 关键： modify verb 'obtain'
Why? / 为什么？
An adverb is needed to modify obtain: easily.
需要副词修饰动词 obtain，所以用 easily。
Teacher Focus / 教学重点： Adjective → adverb.

(e) thinks → think

Original error / 原错误： thinks
Correct answer / 正确答案： think
Key clue / 关键： imperative after Stay positive and...
Why? / 为什么？
The coordinated command uses the base verb: Stay positive and think...
这是并列祈使句，动词用原形 think。
Teacher Focus / 教学重点： Imperative form.

(f) sets → set

Original error / 原错误： sets
Correct answer / 正确答案： set
Key clue / 关键： imperative 'Always set'
Why? / 为什么？
The sentence gives advice in imperative form, so use set.
句子是建议/祈使语气，因此用 set。
Teacher Focus / 教学重点： Imperative V1.

(g) improves → improvements

Original error / 原错误： improves
Correct answer / 正确答案： improvements
Key clue / 关键： continuous + noun
Why? / 为什么？
The phrase needs a noun: continuous improvements.
continuous 后面需要名词 improvements。
Teacher Focus / 教学重点： Word class + plural.

(h) drinks → drink

Original error / 原错误： drinks
Correct answer / 正确答案： drink
Key clue / 关键： you + present simple/base form
Why? / 为什么？
With subject you, use drink.
主语 you 搭配动词原形 drink。
Teacher Focus / 教学重点： Subject–verb agreement.

(i) yours → your

Original error / 原错误： yours
Correct answer / 正确答案： your
Key clue / 关键： before noun 'body'
Why? / 为什么？
Use your before the noun body.
body 前用 your；yours 不能直接修饰名词。
Teacher Focus / 教学重点： your + noun.

(j) properly → proper

Original error / 原错误： properly
Correct answer / 正确答案： proper
Key clue / 关键： before noun 'meals'
Why? / 为什么？
An adjective is needed before the noun: proper meals.
名词 meals 前需要形容词 proper。
Teacher Focus / 教学重点： Adverb → adjective.
