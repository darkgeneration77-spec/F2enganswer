Form 2 English VS — Gapped Text Set 5

Smartphones — Teacher’s Reference Version
Answer Key: 1B · 2E · 3D · 4H · 5A · 6F

Original Article / 原文

Smartphones are now an inseparable part of everyday life. 1. ______ We can stay connected via emails, video calls, text messages and voice calls. We can surf the Internet whenever we want. 2. ______ We can download songs, watch movies, read news, play games and carry out bank transactions. We can also shop online. 3. ______ We only need to purchase the item and wait for delivery. We can store important data on our phones. 4. ______ We can also work and communicate while moving. 5. ______ Smartphones can protect and equip us during emergencies. 6. ______ However, we must not depend on smartphones too much.

Options A–H

A. Smartphones can be especially helpful during emergencies.
B. Smartphones allow us to communicate with our family and friends.
C. We can easily connect to others via social networking sites.
D. We can download and install any shopping application that helps us save time and effort.
E. Smartphones allow us to access many applications for various purposes.
F. In conclusion, smartphones bring many conveniences to our lives.
G. There is almost no limit to what you can do with a smartphone these days.
H. We can even create and share information with others.

Gap 1

Answer / 答案： B — Smartphones allow us to communicate with our family and friends.
Key clue / 关键： family and friends examples
Why? / 为什么？
B is the topic sentence for emails, calls and messages.
B 是主题句，后面列 emails、calls、messages。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.

Gap 2

Answer / 答案： E — Smartphones allow us to access many applications for various purposes.
Key clue / 关键： songs/news/games/banking
Why? / 为什么？
E introduces many applications for different purposes.
E 先总说 many applications，后面才列具体用途。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.

Gap 3

Answer / 答案： D — We can download and install any shopping application that helps us save time and effort.
Key clue / 关键： shop online
Why? / 为什么？
D explains shopping applications.
前文谈网购，D 直接对应 shopping application。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.

Gap 4

Answer / 答案： H — We can even create and share information with others.
Key clue / 关键： store data / share info
Why? / 为什么？
H extends storing information to creating and sharing it.
H 从 store data 延伸到 create/share information。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.

Gap 5

Answer / 答案： A — Smartphones can be especially helpful during emergencies.
Key clue / 关键： emergencies
Why? / 为什么？
A introduces the emergency paragraph.
后面整段谈 emergencies，所以 A 是主题句。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.

Gap 6

Answer / 答案： F — In conclusion, smartphones bring many conveniences to our lives.
Key clue / 关键： However
Why? / 为什么？
F gives the positive conclusion before the contrast.
F 先总结便利，However 再转折提醒不要依赖过度。
Teacher Focus: 前句 + 后句 → pronoun reference → connector → time sequence → topic continuity.
