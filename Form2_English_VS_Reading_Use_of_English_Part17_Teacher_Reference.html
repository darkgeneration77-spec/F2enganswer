答案完全跟上传答案表。老师版重点解释每个正确词在句子里应检查的语法位置。

(a) stop

Correct answer / 正确答案： stop
Key Grammar / 关键语法： verb form / 动词形式
Why? / 为什么？
Use the base verb stop where the sentence structure requires the verb in its basic form.
句型需要动词原形时使用 stop。
Teacher Focus / 老师讲解： 先找前面的 modal / to / imperative，再决定动词形式。

(b) we

Correct answer / 正确答案： we
Key Grammar / 关键语法： subject pronoun / 主格代词
Why? / 为什么？
We is used as the subject of the clause.
we 在这里作句子的主语。
Teacher Focus / 老师讲解： 主语用 we；宾语用 us。

(c) turn

Correct answer / 正确答案： turn
Key Grammar / 关键语法： verb/collocation / 动词搭配
Why? / 为什么？
The correct expression in the sentence uses turn.
这里的正确搭配需要 turn。
Teacher Focus / 老师讲解： 留意 turn on / turn off 等 phrasal verbs。

(d) place

Correct answer / 正确答案： place
Key Grammar / 关键语法： noun/verb choice / 词性
Why? / 为什么？
The context requires place in this position.
根据句子结构，这里应使用 place。
Teacher Focus / 老师讲解： 先判断空格需要 noun 还是 verb。

(e) their

Correct answer / 正确答案： their
Key Grammar / 关键语法： possessive adjective / 所有格
Why? / 为什么？
Use their before a noun belonging to 'they'.
their 放在名词前，表示“他们的”。
Teacher Focus / 老师讲解： their + noun；them 是宾格。

(f) is

Correct answer / 正确答案： is
Key Grammar / 关键语法： subject–verb agreement / 主谓一致
Why? / 为什么？
The singular subject takes is.
单数主语搭配 is。
Teacher Focus / 老师讲解： 先圈主语，再决定 is/are。

(g) house

Correct answer / 正确答案： house
Key Grammar / 关键语法： singular noun / 单数名词
Why? / 为什么？
The context requires the singular form house.
根据上下文，这里需要单数 house。
Teacher Focus / 老师讲解： 检查前面的 a/one/each。

(h) covered

Correct answer / 正确答案： covered
Key Grammar / 关键语法： past participle / 过去分词
Why? / 为什么？
Covered is used in the passive/descriptive structure.
covered 用于被动结构或描述被覆盖的状态。
Teacher Focus / 老师讲解： be + past participle。

(i) recommended

Correct answer / 正确答案： recommended
Key Grammar / 关键语法： past participle / 过去分词
Why? / 为什么？
The sentence requires recommended in a passive or completed form.
句子需要 recommended 作为过去分词。
Teacher Focus / 老师讲解： 注意 recommend / recommended 的句型位置。

(j) my

Correct answer / 正确答案： my
Key Grammar / 关键语法： possessive adjective / 所有格
Why? / 为什么？
My is used before a noun belonging to the speaker.
my 放在名词前表示“我的”。
Teacher Focus / 老师讲解： my + noun；mine 单独使用。
