Part 2 — Error Correction: Hula Hooping

Answers: 1 strengthens · 2 works · 3 some · 4 challenges · 5 but · 6 against · 7 while · 8 counted

Passage focus / 文章主题： Benefits of hula hooping and how to keep the hoop moving.
Q1. strengthened → ______
Answer / 答案： strengthens
Key clue / 关键： present simple, singular subject
Why? / 为什么？
The subject is Aerobic exercise, a singular noun, so the present simple verb takes -s: strengthens.
主语 Aerobic exercise 是单数，所以一般现在时动词要加 -s，用 strengthens。
Teacher Focus / 教学重点： Subject–verb agreement.
Q2. working the abdominal muscles → ______ the abdominal muscles
Answer / 答案： works
Key clue / 关键： present simple
Why? / 为什么？
The subject hula hooping is singular, so use works.
主语 hula hooping 是单数，因此用 works。
Teacher Focus / 教学重点： Gerund phrase as singular subject.
Q3. requires the mental flexibility → requires ______ mental flexibility
Answer / 答案： some
Key clue / 关键： determiner
Why? / 为什么？
The answer scheme uses some before the uncountable noun phrase “mental flexibility”.
答案表使用 some mental flexibility。
Teacher Focus / 教学重点： some + uncountable noun.
Q4. challenging the brain → ______ the brain
Answer / 答案： challenges
Key clue / 关键： present simple, singular subject
Why? / 为什么？
The subject is Switching the direction of the hoop, which functions as singular, so use challenges.
Switching... 整个动名词短语作单数主语，所以用 challenges。
Teacher Focus / 教学重点： Subject–verb agreement.
Q5. may be difficult at first and don't give up → difficult at first ______ don't give up
Answer / 答案： but
Key clue / 关键： contrast connector
Why? / 为什么？
The meaning is contrast: it may be difficult, but you should not give up.
前面说可能很困难，后面却鼓励不要放弃，是转折关系，所以用 but。
Teacher Focus / 教学重点： but = contrast.
Q6. place it along your back → place it ______ your back
Answer / 答案： against
Key clue / 关键： preposition/collocation
Why? / 为什么？
The hoop should be placed against your back, meaning touching/supporting against it.
呼啦圈要贴着背部，所以用 against。
Teacher Focus / 教学重点： Preposition in physical position.
Q7. spin it in one direction however swinging your hips → ______ swinging
Answer / 答案： while
Key clue / 关键： simultaneous actions
Why? / 为什么？
While links two actions happening at the same time: spin the hoop while swinging your hips.
spin 呼啦圈和 swing hips 是同时进行的动作，所以用 while。
Teacher Focus / 教学重点： while = at the same time.
Q8. to be counting as an aerobic exercise → to be ______
Answer / 答案： counted
Key clue / 关键： passive voice
Why? / 为什么？
The passive structure is be counted as.
固定被动结构是 be counted as，表示“被算作”。
Teacher Focus / 教学重点： be + past participle.
