Answer Summary
Topic / 主题： Qualities of a good friend
Answer Key: a aware · b their · c offer · d your · e actually · f shut · g through · h them · i and · j hang

本版本把答案直接放回错误词旁边，并解释 为什么要这样改、关键语法是什么。答案严格按照上传答案表。

(a) awareness → aware

Original error / 原错误： awareness
Correct answer / 正确答案： aware
Key clue / 关键： be + adjective
Why? / 为什么？
After be, use the adjective aware.
be 后面需要形容词 aware。
Teacher Focus / 教学重点： Word class.

(b) theirs → their

Original error / 原错误： theirs
Correct answer / 正确答案： their
Key clue / 关键： before noun 'feelings'
Why? / 为什么？
Use the possessive adjective their before a noun.
feelings 前要用 their，theirs 不能直接修饰名词。
Teacher Focus / 教学重点： their + noun.

(c) offering → offer

Original error / 原错误： offering
Correct answer / 正确答案： offer
Key clue / 关键： can + base verb
Why? / 为什么？
After modal can, use the base verb offer.
can 后面接动词原形 offer。
Teacher Focus / 教学重点： Modal + V1.

(d) you're → your

Original error / 原错误： you're
Correct answer / 正确答案： your
Key clue / 关键： before noun 'friends'
Why? / 为什么？
The sentence needs the possessive adjective your.
friends 前需要所有格 your；you're = you are。
Teacher Focus / 教学重点： your vs you're.

(e) actual → actually

Original error / 原错误： actual
Correct answer / 正确答案： actually
Key clue / 关键： modify verb 'value'
Why? / 为什么？
An adverb is needed to modify the verb, so use actually.
这里需要副词修饰 value，因此用 actually。
Teacher Focus / 教学重点： Adjective → adverb.

(f) shuts → shut

Original error / 原错误： shuts
Correct answer / 正确答案： shut
Key clue / 关键： they = plural
Why? / 为什么？
With plural subject they, use shut, not shuts.
主语 they 是复数，因此用 shut。
Teacher Focus / 教学重点： Subject–verb agreement.

(g) by → through

Original error / 原错误： by
Correct answer / 正确答案： through
Key clue / 关键： go through a hard time
Why? / 为什么？
The fixed expression is go through a hard time.
固定搭配 go through a hard time，表示经历困难时期。
Teacher Focus / 教学重点： Collocation.

(h) their → them

Original error / 原错误： their
Correct answer / 正确答案： them
Key clue / 关键： cheer + object pronoun
Why? / 为什么？
After cheer, use the object pronoun them.
cheer 后面需要宾格 them。
Teacher Focus / 教学重点： Object pronoun.

(i) therefore → and

Original error / 原错误： therefore
Correct answer / 正确答案： and
Key clue / 关键： keep trying to help and comfort
Why? / 为什么？
The two actions are joined with and.
help 与 comfort 是并列动作，所以用 and。
Teacher Focus / 教学重点： Parallel actions.

(j) hanging → hang

Original error / 原错误： hanging
Correct answer / 正确答案： hang
Key clue / 关键： have to + base verb
Why? / 为什么？
After have to, use the base verb hang.
have to 后接动词原形 hang。
Teacher Focus / 教学重点： have to + V1.
